# Homebrew formula

Source of truth for the formula (**v0.5.0**). Publish by copying to
[`latentmeta/homebrew-tap`](https://github.com/latentmeta/homebrew-tap) as `Formula/zerum.rb`.

After tagging `v0.5.0`, fill `sha256` lines from the GitHub Release `SHA256SUMS` file.
See [docs/DISTRO_CLOSURE_v0.5.0.md](../../docs/DISTRO_CLOSURE_v0.5.0.md).

```bash
brew install latentmeta/tap/zerum
zerum --version   # 0.5.0
```
