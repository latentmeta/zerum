Source of truth for the formula (**v0.4.1**). Publish by copying to
[`latentmeta/homebrew-tap`](https://github.com/latentmeta/homebrew-tap) as `Formula/zerum.rb`.

See [docs/DISTRO_CLOSURE_v0.4.1.md](../../docs/DISTRO_CLOSURE_v0.4.1.md).

brew install latentmeta/tap/zerum
zerum --version   # 0.4.1
